# IRL Survey Graph

An interactive companion to the survey of reinforcement learning from human and foundation-model feedback, with experiment-level robotics evidence.

The application is in [`I-graph/`](I-graph/). See its [guide, evidence scope and build instructions](I-graph/README.md).

```sh
python3 -m http.server 8000 --directory I-graph
```

Open `http://localhost:8000` and choose **Robotics evidence**. No database, package installation or API key is required. `I-graph/index.html` can also be opened directly with the accompanying files present.

This is a research draft. Its evidence review is dated **24 November 2026**; collection counts are not exhaustive literature totals.
